# 🎄 Evelique Cafe

A cozy, Christmas-themed digital cafe menu created as a school project by **John Ludovic Cabahug** (Grade 9 – Citrine).

🔗 **[View Live Site on Vercel](https://evelique.vercel.app)**

---

## ✨ About the Project

**Evelique Cafe** is a festive menu interface designed to showcase holiday-inspired drinks, pastries, and seasonal treats. This project was built from scratch to practice web development and design skills during the holiday season.

### Key Highlights
* **Festive Theme:** Styled with classic Christmas colors, typography, and holiday cheer.
* **Custom Menu:** Features a curated selection of seasonal beverages and cafe items.
* **Live & Accessible:** Deployed on Vercel for fast, easy viewing on any device.
* **Student-Built:** Designed and coded entirely from the ground up.

---

## 🛠️ Built With & Deployed On
* **Code:** *HTML5, CSS3, JavaScript*
* **Hosting:** [Vercel](https://vercel.com)

---

## 🚀 How to Run Locally
1. Clone or download this repository to your computer.
2. Open the project folder and launch `index.html` in your browser (or run your local dev server).
